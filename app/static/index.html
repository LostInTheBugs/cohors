SimulationCraft pour la guilde Personnages Administration Déconnexion

Colle ton export /simc (en jeu : tape /simc puis copie tout le texte) et lance la simulation.

❓ Comment obtenir l'export /simc ?
  1. Installe l'addon SimulationCraft dans WoW (via CurseForge ou WowUp, comme tes autres addons).
  2. En jeu, tape /simc dans le chat : une fenêtre s'ouvre avec tout ton profil (équipement, talents, sacs et banque).
  3. Copie le texte (bouton Copy dans la fenêtre), colle-le dans le champ ci-dessous, puis lance la simulation.

Rien d'autre à installer : le moteur de simulation tourne entièrement sur le serveur.
