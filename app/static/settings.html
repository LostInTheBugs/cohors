🤖 Bot Discord …

Annonce automatiquement les nouveaux rapports de raid (Warcraft Logs) et les mouvements de guilde (arrivées / départs) dans un salon Discord.

❓ Créer l'application Discord (une seule fois)
  1. Ouvre le Portail développeurs Discord → New Application (nom : « Cohors »).
  2. Copie l'Application ID (General Information) → colle-le ci-dessous.
  3. Onglet Bot → Reset Token → copie le token → colle-le ci-dessous (secret).
  4. Clique 📎 Lien d'invitation, ouvre-le et ajoute le bot à ton serveur — il faut la permission « Gérer le serveur » sur le serveur visé (sinon, transmets le lien à un administrateur du serveur).
  5. 🔄 Charger les salons, choisis le salon, 💾 Enregistrer puis 📨 Message de test.

Au premier passage, le bot pose ses références (aucune annonce rétroactive) : les annonces démarrent à partir de l'activation.

🔑 Clés API

Clés utilisées par le site pour interroger les services externes (roster et objets Battle.net, rapports de raid et parses Warcraft Logs). Enregistrées ici, elles sont prioritaires sur le fichier de configuration du serveur — pratique pour les renouveler sans redéployer.

Les secrets ne sont jamais réaffichés (seuls les 4 derniers caractères). Un test de connexion est fait à l'enregistrement.

🏰 Guilde (royaume & WCL)

Où le site trouve ta guilde : roster et fiches de personnages (Battle.net), rapports de raid (Warcraft Logs). Les valeurs enregistrées ici remplacent celles du fichier serveur — indispensable pour installer le site sur une autre guilde.
